# Cybersecurity Asset Inventory System

## Description
A simple C program to manage and track IT assets in an organization.

## Features
- Add Asset
- Search Asset
- Update Asset
- Delete Asset
- Display Assets

## Asset Details
- Asset ID
- Asset Name
- Asset Type
- IP Address
- Operating System
- Department
- Risk Level
- Security Status

## Technologies Used
- C Programming
- Structures
- Arrays
- Functions

## How to Run

Compile:
gcc asset_inventory.c -o asset_inventory

Run:
./asset_inventory
